# 随包前端资源

- echarts.min.js：Apache ECharts 5.6.0，来自官方 npm 包 `echarts@5.6.0/dist/echarts.min.js`。许可证见 ECHARTS_LICENSE.txt，Apache-2.0。
- world.js：来自 `echarts-countries-pypkg==0.1.6/resources/echarts-countries-js/world.js`，包元数据声明 MIT。地理底图用于课程示意，不代表对边界归属的认定。
- PyVis：通过 Python 包生成 HTML，内嵌 vis-network 资源。库授权与内嵌脚本头部声明保留。https://github.com/WestHealth/pyvis

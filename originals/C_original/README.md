## 5. 三个"能体现深度"的工程细节（建议单独一页）

### 坑 1：`出口至` 少一个字段，会吃掉 20% 的稀土出口数据

A 的 06 关系表里，`出口至` 只有"起→终"，没有矿种。而 `中国→日本` 有 **两条**：一条稀土（30%）、一条石墨（20%）。
如果按"起点 + 终点"去 `MERGE`，这两条会被合并成一条——**数据静默丢失，还对不上账**。
解决：从 note 文本判定矿种，17 条全部唯一命中，一条对不上就报错退出（不猜）。
**PPT 一页就能讲完，且是真实踩过的坑，比背概念有说服力。**

### 坑 2：140 条出产边里，97 条产量是 0

A 按"缺失值显式标注"的规范，把没有规模产量的国家记成 `quantity=0 / 无规模产量`。
**断供推演的第一步不是 BFS，是先过滤零产量**——否则"刚果金断供"会顺着它 0 吨的锂产量，推出根本不存在的传导路径。
这条规则现在写进了推演查询的 `WHERE toFloat(p.quantity) > 0`。

### 坑 3：LLM 三元组里有 19 行占位实体，且 B 已经判过"对不对"

B 的 `new_triples.csv` 里 `NEW:嘉能可`、`NEW:欧盟` 这种 ID 是**没解析的实体**，直接导会造出 19 个"没有属性、没有类型"的垃圾节点。
v1 我挡在图外了（只导能解析的 16 条）；v2 后 B 把 16 个占位实体全部落成正式 ID（15 新建 + 1 合并），并且**在 `new_triples_v2.csv` 里加了 `import_flag` 列**：28 条"可入图"、37 条"不入图"、8 条"部分正确"打 `review_flag`。
我按 B 的标记导——**不再自己猜哪条能进**，最终导 26 条（2 条与 06 表重复自动跳过），0 条占位残留。

## 6. 必须知道的"不完美"（老师/同学问起时怎么答）

| # | 问题 | 说明 | 影响 |
|---|---|---|---|
| 1 | **数据规模小（143 节点）** | 规模不是目标 | 说辞：**Schema 表达力和可推演性才是**，321 条业务边覆盖 7 矿 / 22 国 / 47 企业 / 21 产品 / 15 事件 |
| 2 | **30 条边打了 `review_flag`** | `confidence<0.80`、`evidence_type=推算`、或 LLM 抽取且 B 判"部分正确" | 推演默认排除这些边，可视化标注"待核实" |
| 3 | **296 条 `CITES` 会让全局图变糊** | 溯源边属于 31 个来源，每个节点平均连 2 条 | 演示时分开看：业务图用 `MATCH (n)-[r]->(m) WHERE NOT r:CITES`，溯源图单独查 |
| 4 | **出产边里 97 条产量为 0** | A 按规范把无规模产量记为 0/无规模产量 | 推演必须 `WHERE toFloat(quantity) > 0`，否则会推出不存在的传导路径 |
| 5 | **欧盟是"超国家组织"却挂在 Country 下** | B v6 把 Country 定义为"国家/地区/超国家组织" | 答辩时指着 `entity_type` 属性解释；数据本身没错 |

## 8. 答辩 Q&A 预备（8 个高频问题）

**Q1 为什么用图数据库，不用 MySQL？**
断供推演本质是"沿边扩散"，关系库要 4 次自连接 JOIN 才能走 3 跳，且路径长度一变 SQL 就得重写；图库一条 Cypher 表达任意跳数，且天然返回路径本身（可视化直接用）。

**Q2 为什么是 5.26 而不是最新版？**
GDS 必须与内核版本严格配对，5.26 ↔ GDS 2.13。选 LTS 保证插件可装、可复现。

**Q3 为什么有些来源节点单独挂着、没有连线？**
31 个来源里 S08、S22 两条登记了但图上没有知识引用它们（A 组采集时拿了但没用上）。这不影响任何结论，查溯源时会看到这两个孤点，如实说明即可。

**Q4 30 条 review_flag 边会不会污染结论？**
不会：推演查询默认 `WHERE NOT coalesce(r.review_flag, false)`，演示时单独用虚线/灰色标注；被排除的只是低置信和 B 判"部分正确"的边。

**Q5 `出口至` 的矿种是你们编的吗？**
不是。v1 时 06 表没这列，我用 note 关键词判定（17 条全部唯一命中）；v2 A 组已正式加 `mineral_id` 列，现在直接读官方值，规则可复核。

**Q6 怎么证明导入没错？**
三重对账：CSV 行数 vs 期望边数 vs 图内实际数，逐类相等（143 节点 / 617 边）；再加孤儿/重复/悬空外键三项检查，业务节点孤儿 0、重复边 0、悬空外键 0。

**Q7 这套东西能复现吗？**
能。两条命令：先跑约束脚本，再跑 `02_import.py`（默认清库重建，反复跑结果一致）。全程不装第三方驱动。

**Q8 如果换一批数据（比如再加 10 个国家）要多久？**
改 CSV 就行，脚本不用动——导入脚本是配置驱动的（表→标签、谓词→关系类型都写在映射表里）。

### 9.1 两张截图用的查询（在 http://localhost:7474/browser/ 里跑）

**图一：钴断供的分层子图**（§7.1 讲那 90 秒时投这张）

```cypher
MATCH p=(c:Country)-[e:PRODUCES]->(:Mineral {name_zh: '钴'})
WHERE toFloat(e.quantity) > 0
RETURN p
UNION
MATCH p=(:Mineral {name_zh: '钴'})-[:SUPPLIES*1..3]->(:Company)
WHERE all(r IN relationships(p) WHERE NOT coalesce(r.review_flag, false))
RETURN p;
```

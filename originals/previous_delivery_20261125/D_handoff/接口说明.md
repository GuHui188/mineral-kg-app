# D 前置交付与接口说明

## 已可开始的工作
使用当前项目完整目录；执行python run_all.py。代码只需Python3.10+与openpyxl。D可以直接用下面接口开始Streamlit壳、pyvis关系图、地图、规则问答及路径高亮。

```python
from d_adapter import KGService
api = KGService()  # 当前已测：本地规范图快照
overview = api.overview()
entities = api.search('宁德时代')
answer = api.answer('刚果金钴断供会影响哪些企业')
scenario = api.simulate('刚果金', '钴', max_hops=4)
trace = api.query('provenance', {'record_id': 'R0191'})
context = api.context('宁德时代的钴上游供应')
```

query统一返回intent/template/parameters/backend/dataset/as_of/answer/rows/graph/highlight_paths/sources/limitations。graph内nodes使用id/name/label；edges使用id/source/target/type/record_ids/source_ids/review_flag。highlight_paths含node_ids与edge_ids，D按ID高亮，无需用中文名称拼接。

规则8类：overview、production、concentration、potential_impact、substitution、policy、upstream、provenance；参数见examples。缺参数返回needs_parameters，不生成假答案。地图用map_country_data.json；欧盟无ISO国家码，map_eligible=False，独立展示，不伪造国家地图位置。

## 尚未验收的数据库步骤
用户已确认本机未安装Neo4j。C/verify_neo4j.py准备好了真实导入、幂等和模板/推演对照检查，但未通过数据库实测。安装启动Neo4j5后配置NEO4J_HTTP_URL/NEO4J_DATABASE/NEO4J_USER/NEO4J_PASSWORD，再运行该脚本，检查reports/neo4j_verification.json中的status=passed后使用KGService('neo4j')。

Neo4j导入只处理dataset命名空间，不删除旧图；不同SHA的同名快照拒绝覆盖。当前没有新dump，也未将旧dump替换成新版。

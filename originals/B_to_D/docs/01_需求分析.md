# 第一部分 需求分析

> 项目：关键矿产与动力电池供应链知识图谱（案例三）
> 负责：B · 知识建模与抽取
> 版本：v1.0（2026-11-16）

## 1.1 项目背景

锂、钴、镍、稀土等关键矿产的储量与产能高度集中于少数国家与企业（如钴的 HHI 指数长期高于 2500，属"高度集中"区间）。与此同时，出口管制、关税、罢工、断航等冲击事件频发，且冲击沿"国家 → 矿产 → 企业 → 产品"链条传导，往往**隔了三至四层**才在下游显现。海关贸易数据、企业年报、政策文本等数据源各自为政，导致风险识别滞后、归因困难。

本项目构建关键矿产—动力电池供应链知识图谱，把国家、企业、矿产、产品、政策事件五类对象连成一张可查询、可推演的网，支撑供应链风险分析与决策。

## 1.2 目标用户

| 用户 | 角色 | 核心诉求 |
|---|---|---|
| **主用户：行业分析师 / 供应链风险管理人员** | 电池厂、整车厂或咨询机构的供应链分析岗 | 快速定位断供风险源、评估冲击传导范围、寻找替代路径 |
| 次用户：政策制定者 | 产业与贸易政策研究岗 | 评估出口管制等政策的影响面与外溢效应 |
| 次用户：投资者 | 新能源产业链投研岗 | 穿透企业上游资源依赖，识别集中度风险 |

选择"行业分析师/供应链风险管理人员"为主用户的理由：该角色的工作本质就是回答"冲击从哪来、隔几层到我这、能不能绕开"，与图谱的多跳推演能力最匹配；政策制定者与投资者的需求可被同一 Schema 覆盖，无需另建模型。

## 1.3 信息需求分析

主用户的典型工作场景拆解为三类信息需求：

1. **结构认知**：某种矿产"谁在产、谁在买、谁在中间"，集中度多高（对应 HHI、份额等指标）；
2. **风险推演**：某国/某企业/某事件发生后，冲击沿供应链传导几层、波及谁（多跳路径查询与影响面计算）；
3. **应对决策**：是否存在替代技术路线或替代供应源（产品—矿产依赖关系与"可替代"关系）。

## 1.5 需求对建模的约束（向下游的输出）

上述能力问题直接决定 Schema 设计必须满足的约束，作为知识建模部分的输入：

1. Q2/Q5 要求"供应""控股"关系**方向明确且可串联**，冲击传导路径上不能断链；
2. Q4/Q6 要求政策事件的发布国、目标国必须建成**边**而非仅作属性，否则无法从国家反查政策；
3. Q3 要求产品与矿产之间存在显式的**"需要"依赖边**（由 04 表 key_minerals 字段转化）；
4. Q6 要求所有事实关系携带**年份属性**，支持时序切片；
5. Q7 要求节点度数与连接结构完整，支持图算法计算。

# 第五部分 知识抽取与评估

> 对应课程任务 4：实体识别、关系抽取、属性抽取 + 抽样人工核对，报告准确率（P/R/F1）。
> 脚本：`scripts/extract_triples.py`（抽取与对齐）、`scripts/audit_and_metrics.py`（核对表与指标）。

## 5.1 抽取方案

**方法选择：大模型抽取（LLM-based IE），辅以规则约束。**

理由：政策文本与新闻为非结构化中文长句，规则/spaCy 方案需要大量人工编写模板，
而课程目标是"懂业务的图谱设计者"——LLM 抽取让我们把精力放在 **Schema 约束与质量评估** 上，
这恰是管理视角的核心，也是本方案的技术创新点之一（Schema 约束抽取）。

**抽取流程（四步）**：

1. **Schema 约束的 Prompt**：实体类型限定为 5 类、谓词限定为 Schema 的 10 种关系，
   并将已知实体标准名注入 prompt（限定长度），要求模型优先复用、禁止推测、逐条给证据句；
2. **结构化输出**：JSON 数组，字段 subject / predicate / object / evidence（证据句强制留痕）；
3. **实体对齐入库**：抽取结果经别名字典（35 家企业全别名 + 中英名）映射为主键，
   非法谓词打标拦截，未命中实体标 `NEW:` 前缀进人工复核队列（对应 4.2 节三级对齐规则）；
4. **质量门槛**：沿用 2.3 节策略，新抽取条目默认 value_status=待核对，人工确认后方可转正。

### 验证的两个重要发现

1. **别名字典缺口**：国家表无 alias 字段，"印尼"这类通称无法对齐到"印度尼西亚"——

## 5.4 指标口径说明

- **严格准确率**：判"正确"的条数 / 核对总数（课程最低要求）；
- **宽松准确率**：正确计 1、部分正确计 0.5；
- **P/R/F1**：P=正确数/抽取总数；R=正确数/该文本人工标注的标准三元组总数（gold）；
- **gold 认定口径**：由 B 逐篇精读原文，按 Schema 允许的 10 种关系、与实体维表一致的
  颗粒度（如 7 类稀土元素归入"稀土"一个节点，不逐元素计数）人工认定，每篇数值写入
  该篇首行 gold_count 列（S11=4，S12=8，S13=4，S20=9，S21=12，S23=10，S24=11，合计 58）；
- **核对分工**：4 人交叉核对（各篇核对者见 audit_sheet.xlsx"核对者"列），
  判定规则为"正确/部分正确/错误"三档，判定理由逐条留痕，可复现。

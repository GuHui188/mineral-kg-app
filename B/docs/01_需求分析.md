# 需求分析整合版

目标用户为课程场景下的产业链研究人员。基于小型现有图谱回答以下8类问题，不宣称完整全球供应链。

| 编号 | 能力问题 | 实现与边界 |
|---|---|---|
| Q1 | 已记录哪些国家生产指定矿产，覆盖多少全球份额？ | 正产量与原share_pct；不是完整国家名录 |
| Q2 | 指定产矿国断供情景下，该矿种关联哪些下游企业？ | 国家→矿产→企业多跳；仅潜在矿种关联，不证明实际采购 |
| Q3 | 有哪些能够避开目标矿种的技术替代候选？ | 方向、完整依赖及条件检查；缺数据不推断独立性 |
| Q4 | 哪些原表政策关联指定目标国，谁发布，何时生效？ | TARGETS国家、ISSUED_BY国家；REGULATED_BY从矿/产品指向事件；不保证当前仍有效 |
| Q5 | 指定企业有哪些供应、股权上游关联？ | 逆向多跳；注册国或股东国不是采购来源国 |
| Q6 | 已记录国家覆盖下的生产集中情况如何？ | 覆盖率和部分HHI；不作全球集中等级判断 |
| Q7 | 指定事实能否回查来源和原记录？ | triple_id/record_ids→业务事实→Source；CITES导航不当事实计数 |
| Q8 | 当前小图中哪些节点的结构中心性较高？ | 有向无权图中介中心性及PageRank；不是风险概率或真实单点依赖损失 |

D按8种意图执行模板（overview/production/concentration/potential_impact/substitution/policy/upstream/provenance）；Q8图算法通过reports/centrality.json另行展示。意图与能力问题不要求一一对应。

缺少历史面板，因此政策前后因果分析不作为已实现功能。原需求中的历史比较保留在originals，不继续作为本版承诺。课程要求至少两项多跳问题由Q2、Q5满足。

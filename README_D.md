# 关键矿产资源知识图谱：系统功能与操作说明

## 启动

双击项目目录下的 `start_D.cmd`，或执行 `python run_D.py`，打开 http://127.0.0.1:8501。
初次运行需要安装 `requirements_D.txt` 中的依赖。项目可使用本地数据快照；连接Neo4j和DeepSeek时，参照 `.env.D.example` 在本机填写 `.env.local`。

## 八个工作区

| 工作区 | 操作与结果 |
|---|---|
| 矿产概览 | 选择矿种，查看登记产量、产国份额、地图、部分HHI及图结构关键节点 |
| 完整目录 | 按类型显示相关字段，按企业产业环节或产品类别筛选；选中一行查看详情，关系计数与详情采用相同显示范围 |
| 图谱检索 | 按名称、别名、ID查询实体，在检索范围中选择1至6跳、关系类型及待核实/未来关系范围 |
| 政策与贸易 | 按发布方和矿种筛选政策，查看事件属性、关联关系与出口方向 |
| 情景分析 | 选择国家与矿种、矿产下游最大层数和关系范围，查看企业路径、产业环节、产品关联、技术候选及其他产国 |
| 智能问答 | 输入自然语言或选择业务模板查询；图谱检索参数位于高级检索设置，可启用AI辅助回答 |
| 构建与审核 | 查看8个产业环节、来源等级与支撑范围、字段字典、64条抽检样本目录、重点记录依据、抽取输入输出及人工审核 |
| 查询与验收 | 查看图分析、12条参数化查询、3个可调参数的情景案例、数据检查及功能对应的方法 |

## 数据范围

收录7个矿种、21个材料产品、48家企业、22个国家/地区、15个政策事件和36个来源。企业产业环节为采矿、冶炼、正极材料、材料、电芯、整车、贸易、回收；企业类型作为独立属性展示。

## 页面操作

工作区按数据浏览、分析应用、方法与质量分组。数据连接选项位于侧栏“连接与设置”。

- 在矿产概览点击“分析该矿产供应链”，带入当前矿产和其首位已登记产国。
- 在完整目录选中表格行，或使用名称选择框打开详情；企业详情可进入上游查询。
- 关系图可切换供应链分层与自由布局，颜色图例对应不同对象类型。
- 结果可选择表格导出CSV，用Excel打开；完整结构化结果仍可下载JSON。

## 与页面结果对应的统计方法

- 产量与份额：读取已登记正产量记录；未收录数值不填零。
- 部分HHI：已登记国家份额的平方和，同时查看记录覆盖率。
- 情景关联：从矿产节点开始，沿供应方向逐层检索，企业按ID去重；国家到矿产的关系不计入下游层数，产品与材料关联单独统计。
- 技术候选：按已有替代关系的实际方向展示，保留条件和关系状态。一般技术候选与Q08中的“避开目标矿产候选”使用不同的筛选条件，界面在相应操作处说明。
- 图结构指标：使用有向无权业务子图，排除来源导航边；PageRank、中介中心性和度均可查看。
- 抽取严格准确率：人工判定正确数除以审核记录数，部分正确不计入正确数。
- 来源回查：用事实记录号和source_ids关联登记来源，展示机构、日期、支撑范围及链接。

## 使用范围

关系状态和适用条件随结果显示。国家产量关联不代表具体企业采购来源；技术候选不等同于已确认可直接切换的方案；其他产国的登记产量不代表可调用剩余产能。

三案例汇总使用与情景分析相同的展示服务，数值随所选遍历深度和关系范围重新计算。

关系范围开关“包含数值缺失、附条件及待确认关系”：包括来源未提供具体数值、仅适用于特定车型或配方，以及依据仍待确认的关系。勾选后，将上述关系一并纳入展示和关联分析，并保留各自的状态说明。
